# 核心体温估计与预测：代码整理说明

本文件夹整理了论文相关代码，供公开前检查和继续完善。当前版本尚不是可以完整复现论文全部表格的发布版。

## 包含的内容

- [Omius 稀疏 TCN 实验](experiments/omius_sparse_tcn/README.md)包含训练脚本、评估脚本和可供核对的汇总结果。
- `ctf/`：MSCA-Net、HE-TCN 和历史特征、直接预测网络头、四模型等权融合的核心代码。
- `experiments/architecture/`：网络结构消融实验脚本及数据约定。
- `research_reference/`：已找到的预测、活动计划、五阶段、外部验证和解释性实验脚本及相关依赖源码。它们保留原实验结构，只作为研究记录，不能直接在新电脑完整运行。
- `examples/` 和 `tests/`：随机模拟数据演示及基本检查，不代表论文结果。
- `REPRODUCIBILITY.md`：复现缺口与发布前需检查的事项。

## 基本检查

使用 Python 3.12，安装与本机匹配的 PyTorch 及 `requirements.txt` 中依赖后，在本目录执行：

```bash
python -m examples.synthetic_demo
python -m unittest discover -s tests
```
